# 通俗版：三角网格上的微分几何量计算

---

## 一、我们要解决什么问题？

### 1.1 从光滑曲面到"渔网曲面"

前半部分课程，我们学的都是**光滑曲面**——就像一块完美的丝绸，每个地方都滑溜溜的，有精确的数学公式描述。但现实中，我们用 3D 扫描仪扫描一只兔子，得到的不是公式，而是一堆**散落的点**。把这些点按一定规则连成三角形，就得到了**三角网格**。

> **一句话理解**：三角网格就是用无数小三角形拼出来的"渔网版"曲面。点越密，网越细，越接近真实的兔子。

打个比方：光滑曲面是一张完美的高清照片，三角网格则是用马赛克拼出来的近似图。采样点密集 → 马赛克块很小，看着就细腻；采样点稀疏 → 马赛克块大，看着就粗糙。

---

### 1.2 两种看待三角网格的方式

**方式一：把它当"拼贴画"**

每个三角形都是一块平整的小玻璃片，把它们边缘粘在一起，就拼成了一个连续的、但是有棱角的曲面。因为每片玻璃都是平的（一阶近似），拼起来的东西只有 **C⁰ 连续**——意思是"连在一起没裂缝"，但**不是光滑的**，摸上去会有棱角感（不满足 C¹ 连续）。

> **打个比方**：就像用很多小平面镜拼成一个 disco 球，整体是个球的样子，但每块镜子之间有明显折痕。

**方式二：把它当"拎起来的渔网"**

先在桌面上铺一张渔网（这是平面上的**图 Graph**，有顶点、边、面），然后把某些结点拎起来放到三维空间中。渔网的拓扑结构（谁跟谁连）完全没变，只是结点的空间位置变了。

> **一句话理解**：三角网格 = 一张被"拎"到三维空间里的渔网。

这个"拎起来"的过程，数学上叫**嵌入（Embedding）**，也是**参数化（Parameterization）**的过程——平面上的每个顶点有 (u, v) 坐标，拎起来后变成了三维的 (x, y, z) 坐标。

---

## 二、图结构基础：网格的"户口本"

### 2.1 图的三要素

三角网格就是一个**图**，由三样东西构成：

- **顶点（Vertex）**：网格中的点，存有空间坐标 (x, y, z)
- **边（Edge）**：连接两个顶点的线段，记作 (vᵢ, vⱼ)
- **面（Face）**：三条边围成的三角形

> 课程假设所有面都是三角形。如果你拿到了一个多边形网格，可以画对角线把它们全切成三角形——这就是**三角化**。

---

### 2.2 知道了哪些信息能推出其他信息？

- **有顶点 V + 有面 F** → 能推出所有边（每个三角形给三条边，去掉重复的就行）✅
- **有顶点 V + 有边 E** → 能找出所有面（从一个点出发沿边找三角形）✅
- **只有边 E + 面 F** → ❌ 推不出顶点！因为顶点坐标是必须单独存储的，只靠连接关系无法知道点的空间位置。

---

### 2.3 OBJ 格式：网格的"极简身份证"

OBJ 是存储三角网格最常用的格式之一，极其简单：

```
v x1 y1 z1    ← 顶点1的坐标
v x2 y2 z2    ← 顶点2的坐标
v x3 y3 z3    ← 顶点3的坐标
v x4 y4 z4    ← 顶点4的坐标
f 1 2 3       ← 面：由顶点1、2、3组成三角形
f 1 3 4       ← 面：由顶点1、3、4组成三角形
```

`v` 开头是顶点，`f` 开头是面。就这么两样。边呢？自己算去。

---

### 2.4 流形 vs 非流形：什么是"正常"的曲面？

**流形（Manifold）**的定义听起来玄乎，其实很简单：

> 曲面上任何一点，你拿显微镜放大看它附近的一小片，都应该**看起来像一个平的圆盘**——可以摊平，没有奇怪的粘连。

**非流形**的情况（都是"病态"的）：

- 一个点附近，两片曲面只是刚好碰到一起（像两个圆锥的尖尖碰在一起）
- 一条边被**三个**面共享（正常一条边只属于两个三角形）

> **打个比方**：正常的衣服布料是流形。但如果你把两件衣服的袖口缝在一个点上，那个点就是非流形的。

**课程约定**：我们只讨论流形。如果你拿到的是非流形网格，需要先"修复"（比如把共享边拆开、删掉多余面）才能进行后续计算。

---

### 2.5 半边结构：网格的"精细台账"

普通的网格数据结构只存"边"，但一条边有两个方向，它属于哪个面也说不清楚。**半边（Half-Edge）**结构把每条物理边拆成**两条方向相反的半边**。

每条半边记录四样信息：

| 字段 | 含义 | 打个比方 |
|------|------|---------|
| `vertex` | 这条半边指向的**终点**顶点 | 一条有向路的终点 |
| `pair` | 与它配对的反方向半边 | 同一根筷子，从A看是朝B，从B看是朝A |
| `face` | 它属于哪个面 | 这条路属于哪个街区 |
| `next` | 同一面内按顺时针/逆时针的下一条半边 | 绕街区走，下一步走哪条路 |

顶点的存储：空间坐标 + 一条从它出发的半边指针
面的存储：一条属于它的半边指针

---

### 2.6 半边结构的"查户口"操作

**由一条半边找两个端点：**
- 起点：`halfedge->pair->vertex`（先翻到反向半边，再取终点）
- 终点：`halfedge->vertex`

**由一条边找两个相邻面：**
- 左面：`halfedge->face`
- 右面：`halfedge->pair->face`

**由一个面找所有半边（绕圈走）：**

```
start = face->halfedge
current = start
循环：
    处理 current
    current = current->next
直到 current 回到 start
```

**由一个顶点找所有出射半边（辐射状找）：**

```
start = vertex->halfedge
current = start
循环：
    处理 current
    current = current->pair->next   ← 翻到反向边，再走下一步
直到 current 回到 start
```

> **打个比方**：这就像在小区里查楼栋。从一个门出发，沿着"下一个门"的指示一直走，最后回到起点，就把整个小区的门都数了一遍。

## 三、微分几何基础：曲线的"弯曲程度"怎么量？

### 3.1 曲线的微分几何

想象你在一条弯曲的山路上开车。在某个点 P：

- **切向量（Tangent）**：你车头朝向的方向
- **二阶导数**：你方向盘转动的趋势
- **副法向量（Binormal）**：垂直于你拐弯平面的方向
- **法向量（Normal）**：指向你正在转弯的圆心方向

这三个向量两两垂直，构成一个**Frenet 标架**——就像你开车时的"三维坐标仪"。

> **退化情况**：如果你停着不动（切向量为零向量），这个坐标仪就不成立了。

**曲率（Curvature）κ**：度量这条路"弯得有多急"。

> **一句话理解**：曲率 = 1 /（拐弯时能画出最大圆的半径）。急转弯 → 半径小 → 曲率大；笔直的路 → 半径无穷大 → 曲率为零。

**曲线第一基本定理**：一条曲线的形状完全由它每一点的曲率决定（平移旋转不算差异）。曲率是曲线的"指纹"。

---

### 3.2 曲面的微分几何

曲面需要两个参数来描述：**S(u, v) = (x(u,v), y(u,v), z(u,v))**。

对两个参数分别求偏导：
- **S_u**：u 方向的变化率（类似曲线的切线）
- **S_v**：v 方向的变化率

这两个向量张成一个平面，叫**切平面（Tangent Plane）**——就是曲面在该点的"最贴近的平面"。

**曲面法向（Normal）**：垂直于切平面的方向。

---

### 3.3 方向曲率：一个方向一个弯曲程度

曲线在某点只有一个切线方向。但曲面上某点的切平面里有**360° 无穷多个方向**。

对每个方向，你可以这样做：
1. 用曲面法向 + 该方向 构成一个"刀片平面"
2. 用这个"刀片"去切曲面
3. 切出来的曲线在该点的曲率，就是**该方向的方向曲率** κ(t)

> **打个比方**：把一个苹果放在桌上，用刀沿不同方向切一刀。每一刀切出的切口在接触点处的弯曲程度都不同。

---

### 3.4 主曲率与欧拉公式

在无穷多个方向曲率中，必然存在：

- **κ₁：最大主曲率**（某个方向的曲率最大）
- **κ₂：最小主曲率**（某个方向的曲率最小）

神奇的是：**这两个方向一定相互垂直**。这是微分几何中非常优美的结论。

**欧拉公式**给了任意方向 θ 的曲率：

$$κ(θ) = κ₁\cos²θ + κ₂\sin²θ$$

> **一句话理解**：任意方向的曲率 = 最大曲率 × cos²θ + 最小曲率 × sin²θ。它就是两个极值的"加权平均"，所以夹在 κ₁ 和 κ₂ 之间。

---

### 3.5 高斯曲率与平均曲率

两个主曲率可以组合出两个关键指标：

- **高斯曲率 K = κ₁ × κ₂**
- **平均曲率 H = (κ₁ + κ₂) / 2**

---

### 3.6 高斯曲率的等距不变性：纸张的"本质弯曲"

**等距变换**：保持曲面上任意两点距离不变的变换。

> **关键结论**：高斯曲率在等距变换下**不变**。

打个比方：
- 一张平坦的纸，高斯曲率处处为零
- 把纸卷成圆柱，纸上的距离没变（你可以把它摊平）
- 所以圆柱的高斯曲率也处处为零

> **一句话理解**：高斯曲率测的是"本质弯曲"——不摊平就不知道的那种弯曲。圆柱看着弯，其实和平面本质相同。

**反向结论**：高斯曲率处处为零的曲面，都能不撕裂不拉伸地展开成平面，叫**可展曲面**。

**三类经典可展曲面**：
1. **柱面**：卷起来的纸
2. **锥面**：漏斗/圆锥
3. **切线面**：一条空间曲线所有切线扫出来的面

---

### 3.7 极小曲面：肥皂膜的秘密

**定义**：平均曲率 H = 0 的曲面。

**物理意义**：在这个曲面上，每一点的两个主曲率互为相反数（κ₁ = -κ₂），一个方向凸、另一个方向等量地凹。所以每个点都是**鞍点（马鞍形状）**。

> **打个比方**：你把一个铁丝圈浸入肥皂水后拿出来，铁丝圈上挂着的薄膜就是极小曲面。表面张力使它的面积收缩到最小。

**建筑应用**：极小曲面屋顶有很多好处——
- 面积小 → 省材料
- 每个点都是鞍点 → 水雪都沿凹方向流走，不积存
- 不会因积雪太重而塌

---

### 3.8 曲面上的点分三类

| 类型 | 条件 | 形状 |
|------|------|------|
| **椭圆点** | κ₁ > 0 且 κ₂ > 0 | 像鸡蛋壳，朝一个方向凸 |
| **抛物点** | 一个主曲率为零 | 像圆柱面，一个方向直、一个方向弯 |
| **双曲点/鞍点** | κ₁ > 0，κ₂ < 0 | 像马鞍，一个方向凸、另一个方向凹 |

## 四、离散微分几何：怎么在"网格"上算弯曲？

### 4.1 核心难题

三角网格的面内是平面（曲率为零），所有"弯曲"都集中在顶点和边处。但顶点处不光滑（不可微），没法直接套用连续微分几何的公式。

怎么办？我们需要**从网格的离散信息（边长、角度、面积）估计出原始光滑曲面的微分属性**。

---

### 4.2 两种思路

**方法一：拟合再计算**
- 取顶点周围一圈邻居点
- 用一个光滑曲面（如二次抛物面）去拟合这些点
- 用拟合曲面的曲率代替真实曲率
- 优点：精度可能高
- 缺点：需要解拟合问题

**方法二：离散直接算**（本课重点）
- 直接从网格的角度、面积等**推出**离散曲率公式
- 理论基础：离散微分几何
- 近 20 年的热门研究领域

---

### 4.3 顶点法向：周围三角形法向的加权平均

顶点 P 周围有好几个三角形，每个都有自己的法向。顶点法向怎么定？

**朴素方法**：所有相邻三角形法向取平均。

**加权平均**：按三角形面积加权（大三角形贡献大）：

$$n_i = \frac{\sum A_j \cdot n_j}{|\sum A_j \cdot n_j|}$$

> **打个比方**：投票决定方向。每个邻居三角形投一票，票权重 = 它的面积。最后归一化。

---

### 4.4 离散平均曲率：余切公式

顶点 i 的平均曲率法向（H·n）的计算公式：

$$H_i n_i = \frac{1}{2A_i} \sum_{j \in N_1(i)} (\cot\alpha_{ij} + \cot\beta_{ij})(v_i - v_j)$$

**各项含义：**
- **N₁(i)**：顶点 i 的**一邻域**——所有与 i 直接相连的顶点
- **αᵢⱼ, βᵢⱼ**：边 (i, j) 两侧的两个三角形的内角
- **Aᵢ**：顶点 i 的局部面积
- **cot**：余切函数（cos/sin）

> **一句话理解**：顶点 i 的平均曲率 ≈ 邻居顶点位置的加权平均与自身位置的差，权重用角度余切算出。

这个公式是从光滑曲面的 Laplace-Beltrami 算子离散推导出来的，是离散微分几何中最核心的公式之一。

---

### 4.5 离散高斯曲率：角度差了多少

离散高斯曲率基于 **Gauss-Bonnet 定理**：

$$K_i = \frac{1}{A_i}\left(2\pi - \sum_j \theta_j\right)$$

- **θⱼ**：顶点 i 周围一圈三角形在 i 处的内角
- **Aᵢ**：顶点 i 的局部邻域面积

**直观理解**：
- 如果顶点周围一圈角度加起来正好是 360°（2π），说明它是平的 → 高斯曲率为零
- 如果角度加起来**小于** 360°，说明顶点"尖出来"了 → 正高斯曲率
- 如果角度加起来**大于** 360°，说明顶点"凹下去"像马鞍 → 负高斯曲率

> **打个比方**：把一张圆纸片剪一个缺口再粘起来，就变成了一个锥。锥尖周围的角度和小于 360°，所以锥尖有正高斯曲率。

---

### 4.6 曲率可视化

**Color Map（颜色映射）**：
- 定义一条颜色渐变条，如蓝 → 绿 → 红
- 蓝色 = 曲率小（平坦），红色 = 曲率大（弯曲厉害）
- 把每个顶点的曲率值映射到颜色，就能直观看到哪里弯得厉害

经典文献：**"Discrete Differential-Geometry Operators for Triangulated 2-Manifolds"（2003）**，值得精读。

## 五、极小曲面的迭代求解：让网格"自己变成肥皂膜"

### 5.1 极小曲面的条件

从余切公式出发，当 H = 0 时：

$$v_i = \frac{\sum_{j \in N_1(i)} w_{ij} v_j}{\sum_{j \in N_1(i)} w_{ij}}$$

其中 wᵢⱼ = cot αᵢⱼ + cot βᵢⱼ。

> **划重点**：顶点 i 在极小曲面上的位置 = 它的邻居顶点位置的**加权重心**（权重 = 余切权重）。

---

### 5.2 迭代算法

**场景**：给你一个铁丝圈（边界），求这个铁丝圈上"张"出的极小曲面。

**步骤**：

1. 初始：给一个带边界的网格（先随便猜一个曲面形状）
2. **固定边界顶点**（这些 = 铁丝圈上的点，不动）
3. 对每个内部顶点：
   - 找到一邻域
   - 用余切权重算出邻居的加权重心位置
   - 把顶点**朝重心方向挪动一小步**（比如挪 10%）
4. 所有顶点同时更新（用**旧位置**计算）
5. 重复迭代，曲面慢慢变成极小曲面

---

### 5.3 重要细节（作业关键！）

> **⚠️ 必须用旧顶点计算新位置**：一轮迭代中，计算所有顶点的新位置时，判断依据是所有顶点的**迭代前的位置**。所以必须先把所有新位置算好，再统一覆盖更新。

> **⚠️ 步长 λ 要小**：推荐 λ = 0.1～0.2。如果 λ = 1（一步到位），算法可能震荡不收敛。

> **⚠️ 边界顶点固定不动**：否则曲面会不断收缩，最终缩成一个点。

> **⚠️ 封闭曲面不适用**：如果网格是封闭的（没有边界），所有顶点一起收缩，最终会塌缩成一个点。极小曲面求解只针对**带边界的开曲面**。

---

### 5.4 怎么找边界？

在半边结构中：
- **内部边**：有两条半边，分别属于两个面
- **边界边**：只有一个面。这条边的 `pair` 半边的 `face` 为空

### 7.2 框架四层架构

```
┌─────────────────────────┐
│      Editor（编辑器）     │
├─────────────────────────┤
│  Render（渲染）│ Logic（逻辑） │
├─────────────────────────┤
│      Foundation（基础）   │
└─────────────────────────┘
```

**基础层**：CMake、C++ 标准库、反射系统、数学库
**渲染层**：DirectX 12、HLSL、Buffer、Shader、Texture、Material、Mesh、FrameGraph、Pipeline
**逻辑层**：ECS 架构
**编辑器层**：场景编辑、组件管理

---

### 7.3 数学库设计

将 Point（点）、Vector（向量）、Normal（法向）分类型设计：

- Point + Vector = Point ✅（点挪个方向还是点）
- Point + Point = Vector ❌（两个点不能相加）
- Vector + Vector = Vector ✅

这种设计通过**组合**方式复用代码（内积、度量、仿射变换等模块可以组合进不同几何类型）。

---

### 7.4 静态反射系统

C++ 没有内置反射（运行时获取类的成员信息），所以框架自建了静态反射库。

**作用**：成员变量信息保存后，Inspector 窗口可以自动显示和编辑。修改成员后重新编译反射文件，UI 自动更新。

---

### 7.5 ECS 架构

**实体（Entity）**：场景中的物体
**组件（Component）**：纯数据（Position、Rotation、MeshFilter 等）
**系统（System）**：纯逻辑，规定对具有特定组件组合的实体做什么操作

优势：数据与逻辑分离，系统可独立激活/停用，依赖关系清晰。

---

### 7.6 作业相关

数据流：
1. 找到含 `DeNoiseData` 组件的实体
2. 把目标网格拖入组件字段
3. 运行系统：三角网格 → 半边网格 → 操作 → 半边网格 → 三角网格回传

半边网格库（Edge Mesh）常用接口：
- 遍历顶点
- 获取顶点位置
- `isOnBoundary()` 判断边界点
- `adjVertices()` 获取一邻域
- `degree()` 获取顶点的度

调试用 `spdlog` 输出信息。

## 八、总结

- 核心内容：离散法向、离散高斯曲率、离散平均曲率
- 半边结构是后续所有网格操作的基础
- 作业量逐步增大，必须**亲手操作**数据结构，不要只依赖框架现成函数
