# 通俗版：让曲线变“顺眼”的魔法，和三角形的世界

## 一、作业点评：B样条与插值型细分实现

### 1.1 这次作业大家做得怎么样？

这次作业的核心是让大家亲手实现两种“画曲线”的算法：**B样条（B-spline）**和**插值型细分（Interpolatory Subdivision）**。

总共收到 29 份作业，其中 10 位同学用 C++ 这类“硬核”语言完成，也有部分同学申请了延期。整体来说，完成度不错，有一些作业让人眼前一亮。

### 1.2 快速回顾：细分到底在干什么？

所谓“细分”，说白了就是**给一条粗糙的折线“美颜”**——不断在折线上插入新的点，让它变得越来越光滑，最后看起来就像一条漂亮的曲线。

这里涉及几种不同的“美颜方案”：

- **Chaikin 细分**：属于**逼近型**细分。好比你先画一个多边形的大致轮廓，Chaikin 算法会帮你“削掉”棱角，逐步逼近一条光滑曲线。它每次迭代都会把每条边切掉一点，角就变圆了。

- **三次细分**：和 Chaikin 的思路类似，但处理点的方式略有不同，相当于另一种“削角”策略。

- **四点细分（4-point Subdivision）**：这是**插值型**细分，意思是**原来给的点一个都不动**，只在每两个相邻点之间“脑补”出新点。它有一个关键参数 **α（阿尔法值）**，用来控制新插入的点相对于原线段的偏离程度。

> **一句话理解**：α 就像做菜时放盐的量——放一点点（0 到 1/8 之间），曲线就很“美味”；放多了（超过 1/8），味道就“炸了”。

具体来说：

- **α 在 0 到 1/8 之间**：细分结果稳定、好看。
- **α 超过 1/8**：曲线开始产生锯齿状的自相似结构，也就是**分形（Fractal）**效果——越细分越“毛茸茸”，像雪花边缘一样。
- α 越大，混乱程度越高，曲线越“放飞自我”。

> **划重点**：工程上我们一般希望曲线光滑可控，所以 α 要控制在 1/8 以内；如果你想玩艺术效果，把 α 调大就能看到分形，那也是一种有趣的实验。

### 1.3 几份让人印象深刻的作业

- **王朝同学**：故意把 α 调到超过 1/8，观察到了漂亮的分形现象。界面做得很好，可以实时切换二次、三次、四点细分，还能控制是否显示原始节点、细分做多少次，交互体验拉满。

- **长金俊同学**：分别实现了二次、三次和四点细分。他把 α 固定在一个小于 1/8 的安全值上，避免了“分形炸裂”。绿色多边形是输入，黄色是输出曲线，一目了然。

- **项羽/陈同学**：一个细节很打动人——鼠标点击时会有波浪动画反馈，虽然是 UI 层面的小功能，但体现了对用户体验的用心。同时支持实时调节 α，想玩分形随时可以调。

- **还有一位同学**：实时性做得特别好，输入点的同时曲线就立刻生成，不用等。支持均匀三次 B 样条和四点细分，点可以拖动编辑，体验非常流畅。

> **老师强调**：优秀代码和报告会分享给大家参考，但**强烈建议自己动手实现一遍**。看懂别人的代码只是“眼睛会了”，只有亲手写过才能真正掌握原理。


## 二、曲线光顺（Curve Fairing）：让曲线不仅“连得上”，还要“摸起来舒服”

### 2.1 连续性的三个等级

“连续”不是笼统的概念，它分等级：

- **C0 连续**：两个曲线段**接上了**，中间没有断开。好比两块木板靠在一起，位置对了，但接头处可能有个尖角。

- **C1 连续**：不仅接上了，而且**切线方向也一致**。两块木板不仅靠在一起，边缘的坡度也相同，摸过去没有突兀的“台阶感”。

- **C2 及以上连续**：连**曲率**都连续。这不是摸上去“不硌手”了，而是看起来**完全光滑**，通常我们把 C2 及以上叫做真正的“光滑”。

> **打个比方**：C0 是两块木板直接拼起来，接缝处可能有棱；C1 是把接缝处打磨得平缓一点；C2 是把整条板子做成一体的流线型，接缝完全看不出来。

### 2.2 什么是“几何连续性”？

还有一种连续性叫**几何连续性（Geometric Continuity）**。它的核心思想是：**曲线的本质形状与你怎么“描述”它无关**。

用参数方程描述曲线时，同样一段直线，用不同的参数化方式写，得到的“参数连续性”可能不同。但曲线还是那条直线——这就是几何连续性的直观含义。

> **一句话理解**：几何连续性关注的是“曲线长什么样”，而不是“你用什么样的尺码去量它”。

在曲线设计中，几何连续性更实用，因为它不依赖具体的表达方式，直接刻画形状本身的品质。

### 2.3 “光顺”是个什么感觉？

**Fairing** 这个词来源于“fair”（公平、光顺）。在造船业里，船体的外壳必须做得非常光顺，否则水阻会增大，船就不“fair”了。

重点在于：**宏观上看起来很光滑的曲线，放大后可能凹凸不平**。一条曲线可能处处 C∞（无限阶连续），但如果它的曲率图像心电图一样上蹿下跳，用工业标准看它依然“不光顺”。

判断光顺的土办法很多：

- 木匠常**用手摸**，哪里有疙瘩一摸就知道。
- 设计师会**打一束光**照在曲面上，看反光的连续性和扭曲程度。
- 最可靠的是**看曲率图**——一条曲线的曲率随着弧长变化的图像，相当于给曲线做了一次“CT 扫描”。

### 2.4 曲率：曲线“弯曲程度”的温度计

要理解光顺，必须先理解**曲率（Curvature）**。

想象你在一条弯曲的道路上开车：

- 急转弯 → 方向盘要打很多 → 弯得厉害 → 曲率大。
- 平缓的弯 → 方向盘轻轻带一点 → 曲率小。
- 直线 → 方向盘不动 → 曲率为零。

数学上，我们可以在曲线某一点画一个“最贴合的圆”，叫做**密切圆（Osculating Circle）**。这个圆的半径 R 越小，说明弯得越厉害；半径越大，说明越接近直线。曲率的定义就是：

**曲率 k = 1 / R**

- 弯得厉害 → R 小 → k 大。
- 越平 → R 大 → k 小。
- 直线 → R 无穷大 → k = 0。

> **划重点**：曲率是“参数化不变量”，也就是说，不管你用什么参数去写这条曲线，它在同一点的曲率值都一样。它反映的是曲线**本身的**弯曲属性，就像一个人的体重，不因为换了把秤就改变。

空间曲线（三维）还有一个额外的量叫**挠率（Torsion）**，描述曲线如何“扭转”出平面，这里先不多说。

### 2.5 光顺到底怎么定义？数学家们吵了很久

“光顺”这个概念在数学上**缺乏一个放之四海皆准的严格定义**。相关研究也不算多，但在工业中却**极其重要**——造船、汽车外壳设计、制鞋楦头、齿轮齿形，全都离不开光顺。

中国数学家**苏步青、刘鼎元**给出了一个经典定义：

1. 曲线必须是 **C2 连续**。
2. **曲率图没有多余的振动**——曲率变化要均匀，不能像过山车一样忽上忽下。

**Farin** 则从另一个角度定义：

- 曲率图应该尽量少地交替递增/递减，也就是**单调分段要少**。
- 后来他自己也修正为：曲率图连续就够了。

还有一种**全局定义法**：找一条曲线，使得它的**弯曲能量**最小。数学上弯曲能量可以写成曲率平方的积分——就像一根弹性钢条，它会自然趋向于弯曲能量最小的形状。

### 2.6 工厂师傅的经验之谈

中国学者在工厂实践中总结了四条经验准则：

1. **光顺既不是全局问题，也不是局部问题，而是“大局部”问题**。也就是说，光不光顺，要看一段“足够长”的区域，而不是死盯一个点。
2. **不需要 C2 那么高的连续性**，稍微弱一点也可以接受。C2 是理想，工程中往往打个折。
3. **必须从曲率出发**研究光顺。不关注曲率，就抓不住“光顺”的牛鼻子。
4. 举几个反例：
   - y = sin(x)：数学上 C∞ 无限光滑，但拐点太多，曲率图上下翻飞，工程上认为**不光顺**。
   - 曲率图全是正的，但自身有很多递增递减段，也**不光顺**。
   - 两段不同半径的圆弧拼在一起，接点处曲率突然跳变，不是 C2，**不光顺**。

### 2.7 现代总结：光顺的四条黄金法则

综合上述，现代几何处理中判断一条曲线是否光顺，大致看四条：

1. 曲线是 **C1 + L1**（比 C2 弱一些，允许曲率有“变差”——用专业术语叫“变差连续”）。
2. **拐点要少**。拐点是曲率符号改变的地方，拐点多了，曲线就像蛇扭来扭去。
3. **曲率图的拐点要少**——曲率的单调段尽量少，曲率的变化要“干脆”，不要反复横跳。
4. **曲率图的变化振幅相对要小**——不能突然从一个极大的弯曲跳到一个极小的弯曲。

### 2.8 怎么把不光顺的曲线“弄顺”？

现实生活中，设计软件输出的曲线可能不光顺。我们需要一些工具来“修图”：

- **粗光顺（Coarse Fairing）**：直接手动拖拽控制顶点，让曲率图变得平缓一些，相当于“大锤敲平”。

- **卡尺法（Knot Removal / 压平）**：移除多余的节点，减少拐点数量。可以想象成拿一把直尺压在弯曲的铁丝上，把它“压直”一点。

- **回弹法（Spring Back）**：模仿物理中的弹性回弹过程，分析切变力的符号变化，减少曲率振动的次数。就像你弯一根钢条，放手后它会弹回来一点，这个“弹”的过程其实在自我光顺。

> **重要提醒**：光顺操作必须在**误差允许范围内微调**。你不能为了光顺把曲线改得面目全非——原来的设计意图、关键尺寸必须保留。

### 2.9 非函数曲线和曲面的光顺

对于函数型曲线（y = f(x)），通常假设“小挠度”，即 y′ 很小、y″ ≈ k。但一般的参数曲线没有这个假设，这时可以用**稀疏优化（Sparse Optimization）**方法来处理：最小化曲率二阶差分的 L1 范数，同时约束原始曲线不要改动太大。这个方法的好处是能自动“捕捉”曲率突变的位置并加以平滑。

曲面的光顺更复杂。早年做法是把曲面分解成两个或三个方向的曲线，分别光顺后再拼起来——有局限，因为方向之间有耦合。现代做法多用**能量法**：最小化主曲率的某种积分。

工业界（比如 CATIA 软件）有个说法叫 **Class A 曲面**：汽车外表那种高品质曲面，通常要求 G3 连续以上（比 C3 更强调几何本质）。

检测曲面光顺有两个“神器”：

- **曲率梳（Curvature Comb）**：在曲面上画出一根根“刺”，刺的长度代表曲率。如果刺排列整齐、长短过渡自然，说明曲面光顺；如果刺忽长忽短、方向乱转，就说明有问题。

- **斑马纹（Zebra Stripes）**：在曲面上投射黑白条纹。如果条纹过渡光滑、没有突然的扭曲和断裂，说明曲面很好；如果条纹像哈哈镜里的影像一样扭曲，曲面就有瑕疵。

> **强调**：光顺在造船、汽车等工业中至关重要，直接关系到流体阻力、材料磨损寿命和美观程度。一个不光顺的船壳，在水里的阻力可能比光顺的高出不少。


## 三、换个视角：曲线曲面都是“映射”

### 3.1 映射观点

从数学上看，曲线曲面都是在做“空间转换”：

- R1 → R1：一元函数，比如 y = f(x)，从一条线映射到另一条线。
- R1 → R2 或 R1 → R3：**曲线**。输入一个参数 t，输出平面或空间中的一个点。
- Rm → Rn（其中 m < n）：**曲面**。比如 R2 → R3，输入二维参数 (u,v)，输出三维空间中的点，这就是一张曲面。
- Rm → Rn（其中 m > n）：**降维/参数化**。比如把三维曲面“铺平”到二维平面，就是 m=2、n=3 的反向操作。

> **打个比方**：曲线就像一条“传送带”——你只给一个数（参数 t），它就把你送到某个位置。曲面则像一张“渔网”——你要给两个数（u 和 v），它才吐出一个空间中的点。

### 3.2 两种建模思路

1. **拟合观点**：你手里有一堆采样点（比如 3D 扫描得到的点云），想找控制顶点去“穿过”或“逼近”这些点。这就是插值、逼近、回归的思想。

2. **设计观点**：控制顶点就是用户的“手柄”。设计师直接拖拽这些点，曲线就跟着变形。这就要求基函数有好的性质，比如**局部性**（拖动一个点只影响附近区域）和**凸包性**（曲线一定落在控制点的凸包里面）。Bernstein 基函数就具备这些好性质。

曲线还可以用不同形式来表达：

- **显式函数**：y = f(x)。简单直观，但一个 x 只能对应一个 y，画不了圆。
- **隐式函数**：F(x,y) = 0。圆就是 x² + y² - r² = 0。图像处理里管这叫**水平集（Level Set）**。
- **参数形式**：C(t)。最灵活，B样条、贝塞尔曲线都是这种。
- **细分曲线**：离散表达，不断插点逼近光滑曲线。

### 3.3 PIA：一种好用的迭代拟合方法

**PIA（Progressive Iterative Approximation）**是一种从控制顶点出发逐步逼近目标曲线的迭代算法：

1. 用初始控制顶点构造一条曲线。
2. 计算曲线上各点与目标点的误差。
3. 根据误差微调控制顶点。
4. 重复迭代，直到收敛。

这个方法实现起来非常简单，由中国学者**齐东旭老师**提出，后来由利宏伟等人进一步发展。它的思路很像“打靶”——第一发偏了就根据偏差修正瞄准，再来一枪，逐步逼近靶心。


## 四、把连续曲线切成“小段”：离散化与采样定理

### 4.1 为什么一定要离散化？

现实世界里的处理和显示都离不开离散化：

- **渲染需要**：GPU 光栅化只认直线段和三角形。再漂亮的曲线，最终都要被切成无数小线段才能在屏幕上画出来。
- **计算需要**：曲线求交等运算如果用解析法太复杂，用线段逼近的话误差可控、实现简单。
- **制造需要**：数控加工中，刀具只能走直线和圆弧路径。你必须把设计好的光滑曲面离散成一道道刀具能走的轨迹。

> **一句话理解**：离散化就是把“无穷”变成“有限”，让计算机和机床能处理它。

### 4.2 采样定理：奈奎斯特-香农的魔法数字

**采样定理**是信号处理中的基石：采样频率必须**至少是信号最高频率的两倍**，才能无失真地恢复原始信号。

应用到曲线采样上：B样条曲线采样可以用**细分（Subdivision）**来做。误差可以通过控制顶点与弦线（连接相邻顶点的直线段）的距离来估计。有实际数据表明，如果精度要求是 10⁻⁶，细分 8 次就够了。

### 4.3 离散曲线的几何量怎么算？

曲线离散成点列后，需要计算曲率、法向等几何量。常用方法有两个：

- **拟合法**：先拟合出一条连续曲线（比如样条），然后对这个连续曲线求解析导数。相当于“还原原图”再量。

- **差分法**：直接用相邻点之间的差来近似导数。弦的斜率代替切线斜率。一阶近似就是线性插值，二阶近似用抛物线——有点类似优化里的梯度下降（一阶）和牛顿法（二阶）的关系。


## 五、自由变形（FFD）与重心坐标：像捏橡皮泥一样的数学工具

### 5.1 自由变形：少数点控制一大片

**自由变形（Free-Form Deformation, FFD）**由 Sederberg 在 1986 年提出。核心思想是：用少数几个控制顶点（比如 n² 个），就能控制一个区域内无穷多个点的变形。

这里有个关键概念叫**代理（Proxy）**：用一个简单的几何体（比如一个控制网格）来代替复杂的目标形状。你捏这个代理，复杂形状就跟着变形。

> **打个比方**：你可以把一张照片贴在一个橡皮框上，然后拉扯橡皮框的几个角，整张照片就会跟着扭曲。你不需要逐个像素去修图，只需要操作几个角点就够了。

FFD 的典型应用包括图像扭曲（Image Warp）、甚至曾经被用来“纠正”比萨斜塔的照片。

### 5.2 重心坐标：点在多边形里的“影响力分配”

对于三角形来说，**重心坐标**是唯一确定的：

任何内部点 p 可以唯一地写成三个顶点的加权和：

**p = α·p₁ + β·p₂ + γ·p₃**，其中 α + β + γ = 1

几何上，α、β、γ 就是对应小三角形的面积与整个三角形面积的比值。

> **打个比方**：想象一个三角形纸板，三个顶点各系一根绳子。你要在纸板上挂一个重物，让它平衡，三根绳子的拉力比例就是重心坐标。

但到了四边形及以上的多边形，重心坐标的表示就**不唯一**了。于是学者们提出了各种不同的定义：

- **Mean Value Coordinates**：用角度 cot 和距离 r 来定义，用途广泛。
- **Harmonic Coordinates**：满足调和方程的坐标，性质很好。
- **Wachspress Coordinates**：另一种经典定义。

重心坐标是图像变形、纹理映射等众多算法的基础工具。如果你感兴趣，可以参考瑞士 Horn 教授维护的重心坐标文献网站，那里有大量资料。


## 六、进入新世界：三角网格（Triangle Mesh）入门

### 6.1 三角网格是什么？

把一张曲面切成无数个小三角形，每个小三角形都是平面片，整体构成一个**分片线性逼近**。这就是三角网格。

GPU 渲染时就是以三角形为基本单位来处理——三角形在硬件中光栅化是最简单的。所以不管你最初的曲面多光滑，最后都要变成三角形的海洋。

网格本质上是一个**二维流形上的平面图**，它的基本构成元素：

- **顶点（Vertex）**：一个三维坐标 (x, y, z)。
- **边（Edge）**：连接两个顶点的线段。
- **面（Face）**：由边围成的区域，三角网格中每个面都是三角形。
- **度（Degree/Valence）**：一个顶点连接的边的数量。网格中顶点的度通常不规则，一般在 3 到 6 之间。

### 6.2 流形：网格的“体检标准”

**二维流形**的意思是：曲面上任意一点，取一个足够小的邻域来看，它就像一张平平的二维圆盘。

> **打个比方**：地球表面就是一个二维流形。你站在地球上任何一个地方，往四周看，地面都是平的（曲率在小范围内可以忽略），像一个圆盘，而不是一个奇形怪状的东西。

**非流形边**：一条边同时被三个或更多面共享，像一本打开的书中间夹着好几页。

**非流形顶点**：该点的邻域不连通，比如两个锥体只共用最尖端的那个顶点。把顶点“切开”后，一个变成两个独立的锥。

本课程后续只会处理流形网格，因为非流形的情况会让算法变得异常复杂。

### 6.3 拓扑概念：网格的“身份证”信息

- **亏格（Genus）**：网格上“洞”的个数。游泳圈是亏格 1，眼镜框（两个洞连着）是亏格 2，球面是亏格 0。
- **可定向（Orientable）**：所有三角形的法线方向能保持一致（用右手法则统一）。莫比乌斯带是不可定向的经典例子——沿中缝走一圈，内外面就翻转了。
- **连通图/平面图**：网格可以“拍平”成一个平面图，顶点的坐标则嵌入在三维空间里。

### 6.4 OBJ 文件格式：网格的“通用名片”

OBJ 格式是网格数据最常见的一种文本格式，长这样：

- `v x y z`：定义一个顶点，索引从 1 开始。
- `f a b c`：定义一个面，由三个顶点的索引构成。

比如：
```
v 0 0 0
v 1 0 0
v 0 1 0
v 0 0 1
f 1 2 3
f 1 2 4
f 1 3 4
f 2 3 4
```
四个顶点、四个面，就构成一个四面体。

> **小建议**：不要自己从零写 OBJ 解析器。这个格式看起来简单，但实际文件里有很多边角情况（注释、法向、纹理坐标等），用成熟的库就好了。

### 6.5 网格的数据结构：怎么存才能查得快？

- **邻接矩阵**：用一个矩阵记录任意两个顶点是否相连。空间浪费较大（大部分元素是零），但适合某些矩阵运算。

- **半边结构（Half-Edge）**：这是网格处理中最经典也最常用的数据结构。它的思想是把每条无向边拆成**两条方向相反的半边**。每条半边存储：
  - 起点
  - 终点
  - 它所属的面
  - 与它配对的那条半边

  这样查询“这个面旁边是谁”“这个顶点的相邻面有哪些”都非常快。

> **一句话理解**：存储多，查询快；存储少，计算多。半边结构就是“用空间换时间”的典型代表。

### 6.6 课程框架和本周小任务

助教提供了一个基于半边结构的网格处理框架（名字叫“无尽”）。它包含两套数据结构：

- **计算层**：半边结构，负责高效查询所有邻接关系。
- **渲染层**：自动把计算网格转换成 GPU 能吃的格式，送入渲染管线。

本周的非正式任务是熟悉这个框架，做三件事：

1. 读取一个 OBJ 文件。
2. 计算每个顶点的法向：做法是把该顶点周围所有面的法向取平均。
3. 沿法向对顶点做微小扰动，幅度可以调整，看看曲面发生什么变化。
