# 几何建模与处理 · 知识体系（速记）

> **主干一句话**：先选表示 → 再拟合构造 → 用微分几何分析 → 靠优化求解 → 干处理与建模。
> 只记关键词；六个分支各配一个记忆钩子。

- **一、表示｜钩子：参·隐·离·细**
  - 参数：Bezier · B 样条 · NURBS · 参数曲面
  - 隐式：f(x)=0 · SDF · 水平集 / Marching Cubes
  - 离散：三角网格 · 点云
  - 细分：Chaikin · B 样条细分 · 四点法
  - 连续性：C^k（参数） · G^n（几何）

- **二、构造与拟合｜钩子：空间·度量·求解（三部曲）**
  - 空间：基函数 — Bernstein · B 样条 · RBF · 张量积
  - 度量：插值 · 逼近 · 最小二乘（法方程）
  - 求解：线性方程组 · 梯度下降
  - 防过拟合：正则化 — 岭回归 · L0 稀疏 · 压缩感知
  - 点集参数化：均匀 · 弦长 · 向心

- **三、分析与度量｜钩子：曲率·拉普拉斯·拓扑**
  - 曲率：主曲率 · 高斯 · 平均
  - 隐含：极小曲面 · 平均曲率流
  - 离散：顶点法向 · Cotangent 权重 · 离散曲率
  - 拉普拉斯算子 · 微分坐标
  - 拓扑：流形 · 半边结构

- **四、处理与变换｜钩子：平·参·简·变·重**
  - 平：光顺去噪 — 拉普拉斯平滑 · 双边滤波 · 能量优化
  - 参：参数化 — Tutte · ABF · ARAP · 割缝 · 图集
  - 简：简化 / LOD — 聚类 · QEM · 渐进网格
  - 变：映射变形 — 双射 · 扭曲度量 · FFD · Cage · Morphing
  - 重：曲面重建 — 采集 → 配准(ICP) → 预处理 → 重建 → 后处理

- **五、优化与求解｜钩子：线·非·约·迭·稀**
  - 线性：最小二乘
  - 非（线性 / 非凸）：梯度下降
  - 约（约束）：等式 / 不等式 · 凸优化
  - 迭（代）：局部—全局（ARAP）
  - 稀（疏）：压缩感知

- **六、建模与生成｜钩子：CAD·生成·纹理·分析**
  - CAD：线框 / 曲面 / 实体 · B-Rep · CSG
  - 生成：数据驱动 · GAN
  - 纹理：二维 / 三维 · 过程式 / 基于样本
  - 形状分析：形状描述子
