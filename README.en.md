# GAMES102 Course Subtitles (SRT)

English | [简体中文](README.md)

[GAMES102: Geometry Modeling & Processing](https://games-cn.org/games102/) is a computer graphics course by Prof. [Ligang Liu](http://staff.ustc.edu.cn/~lgliu/) at University of Science and Technology of China (USTC), focusing on modeling, processing and analysis of geometric curves and surfaces. The [Bilibili video playlist](https://www.bilibili.com/video/BV1NA411E7Yr/) contains 15 lectures.

This repository hosts Chinese subtitles (SRT format) for all 15 lectures. The number prefix `NN-` in each filename matches the Bilibili part number, so subtitles can be loaded directly with the videos.

## Per-Lecture Summaries

Each lecture ships with a detailed Chinese summary (pXX-topic.md, in the same directory as its subtitle), generated by DeepSeek V4 Pro (non-thinking mode) from the full transcript, covering the key points, formulas, algorithms, examples and homework walkthroughs of that lecture.

- Filenames match part numbers, e.g. p01-课程介绍.md for p01.
- Summaries are AI-generated; please refer to the original videos for accuracy.
