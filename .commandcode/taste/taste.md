# Taste

## Communication

- Uses Simplified Chinese and expects replies in Chinese; gives very terse, imperative instructions (e.g. "分3个文件夹") and relies on the assistant to inspect context and ask clarifying questions when the request is ambiguous. Confidence: 0.7

## Documentation & Content Organization

- Prefers content organized as a self-contained conceptual knowledge system rather than mirroring the source material's structure (e.g. rejects lecture-by-lecture/课件-driven breakdowns in favor of a concept-driven hierarchy). Confidence: 0.8
- Wants extraneous, topic-irrelevant details stripped out (platform intros, homework reviews, lecture numbering/episode IDs) — keeps only subject-matter content. Confidence: 0.75
- Prefers limited granularity/depth in outlines (roughly three levels), and pushes back when a deliverable is "有点太细了". Confidence: 0.75
- Values study-oriented / memory-aid output: wants bare keywords, one-line main trunks, and mnemonic hooks rather than explanatory prose, so material can be used for quick recall/自测速记. Confidence: 0.8
