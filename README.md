# GAMES102 课程字幕（SRT）

[GAMES102：几何建模与处理](https://games-cn.org/games102/) 是中国科学技术大学 [刘利刚](http://staff.ustc.edu.cn/~lgliu/) 老师开设的计算机图形学系列课程，聚焦几何曲线曲面的建模、处理与分析。[B 站视频合集](https://www.bilibili.com/video/BV1NA411E7Yr/) 共 15 集。

本仓库收录该合集全部 15 集的中文字幕（SRT 格式），文件名 `NN-标题.srt` 中的编号与 B 站分 P 序号一一对应，可直接配合视频加载使用。

仓库结构：`字幕/` 存放全部 SRT 字幕，`总结/` 存放每讲的详细总结，`通俗版/` 存放对应的通俗版总结。

## 每讲总结

每集字幕配套一份 AI 生成的**详细中文总结**（文件 `总结/pXX-主题.md`），由 DeepSeek V4 Pro（非思考模式）依据完整字幕生成，覆盖该讲的知识点、公式、算法步骤、示例与作业讲解，可直接用于复习和检索。

- 文件名与分P对应，如 `总结/p01-课程介绍.md` 对应 p01。
- 每篇总结还配有一份**通俗版**（`通俗版/p01-课程介绍-通俗版.md`），用生活化类比讲清专业概念，适合零基础入门阅读。
- 总结为 AI 自动生成，个别表述可能不准确，请以原视频为准。
