# 离散曲面与三角网格上的微分几何量计算

## 一、课程引入：从光滑曲面到三角网格

### 1.1 课程背景

前半个课程讨论了光滑曲面的表达，包括基函数、连续函数构成的曲面与曲线表达。然而在实际应用中，特别是随着扫描仪的广泛使用，我们更多获得的是曲面上点的采样。这些采样点构成了**三角网格（Triangle Mesh）**：

- 采样点密集 → 三角网格精细
- 采样点稀疏 → 三角网格粗糙

以兔子曲面为例：原始光滑曲面存在，但其方程未知，通过采样获得离散点后连接成三角网格，形成对原始曲面的逼近表达。

### 1.2 理解三角网格的两种观点

**观点一：分片线性逼近（Piecewise Linear Approximation）**

将相邻红点连成三角形，构成一张无缝隙、连续的**分片线性曲面**。每个三角形是一个平面，整个网格是对原始光滑曲面的低阶（一次）逼近。从泰勒展开角度看，每个平面片可视为在某点的**一阶展开**。

> **注意**：该逼近只有 C⁰ 连续，不满足 C¹ 连续，因为三角形之间的拼接不可能光滑。

**观点二：图的嵌入 / 提升（Graph Embedding / Lifting）**

三角网格本质上是一个 **Graph**（图），由顶点（Vertex）、边（Edge）和面（Face）构成。先在平面上定义图的拓扑结构，再将顶点"提升"到三维空间中的位置。拓扑关系不变，仅顶点位置发生变化。

- 此过程类似于将渔网拎起形成曲面的过程
- 从拓扑学角度看，这是从低维到高维的**嵌入（Embedding）**
- 该参数域中每个顶点对应一个 (u, v) 坐标，空间坐标为 (x, y, z)，因此也是**参数化（Parameterization）**
- 本质上，三角网格是二维流形（2-Manifold）的离散表达

## 二、图结构基础与三角网格数据结构

### 2.1 图的基本概念

图由以下要素组成：
- **顶点集合（V）**：包含每个节点的空间坐标
- **边集合（E）**：顶点之间的连接关系，一条边由 (vᵢ, vⱼ) 定义
- **面集合（F）**：由三条边围成的三角形

在本课程中，假设所有面均为三角形。任何多边形网格都可以通过对角线连接的方式**三角化**为三角网格。

### 2.2 拓扑信息之间的互推

- **给定顶点 V 和面 F** → 可由每个三角形的三条边推出所有边，去除重复后得到边集合
- **给定顶点 V 和边 E** → 从一个点出发沿相邻边逐步寻找，可找回所有面
- **仅给定边 E 和面 F** → ❌ 无法推出顶点信息（顶点信息必须给定）

### 2.3 OBJ 格式示例

```
v x1 y1 z1
v x2 y2 z2
v x3 y3 z3
v x4 y4 z4
f 1 2 3
f 1 3 4
```

OBJ 格式极为简洁：`v` 开头表示顶点坐标，`f` 开头表示面（三角形三个顶点索引）。早期 OBJ 格式只存储这两类信息，边可从中推导。

### 2.4 流形与非流形（Manifold vs Non-Manifold）

**流形的定义**：曲面上任意一点的无穷小邻域都拓扑同胚于一个圆盘（二维开集）。

**非流形的例子**：
- 某点附近有两个不相连的面
- 两个圆锥共享一个顶点
- 一条边被三个面共享

> **课程约定**：后续课程仅讨论流形结构。非流形结构需要先转化为流形（如将共享边拆分、删除多余面等），再进行微分几何计算。

### 2.5 半边结构（Half-Edge Data Structure）

**核心思想**：将一条边拆分为两个方向相反的**半边（Half-Edge）**。

每条半边存储以下信息：
| 字段 | 含义 |
|------|------|
| `vertex` | 该半边的末端顶点 |
| `pair` | 与该半边配对的反方向半边 |
| `face` | 该半边所属的面 |
| `next` | 同一面内按顺序的下一条半边 |

顶点存储：
- 空间坐标
- 指向该顶点出射的一条半边

面存储：
- 指向该面内的一条半边

### 2.6 半边结构的邻接查询

**由一条半边找两个端点**：
- 第一个顶点：`halfedge->vertex`
- 第二个顶点：`halfedge->pair->vertex`

**由一条边找两个相邻面**：
- 第一个面：`halfedge->face`
- 第二个面：`halfedge->pair->face`

**由一个面找所有半边**：
```
start = face->halfedge
current = start
do {
    // 处理 current
    current = current->next
} while (current != start)
```

**由一个顶点找所有出射半边**：
```
start = vertex->halfedge
current = start
do {
    // 处理 current
    current = current->pair->next
} while (current != start)
```

### 2.7 常用开源几何处理库

| 库名 | 特点 |
|------|------|
| **CGAL** | 最大、最有名的计算几何算法库，工业商用广泛 |
| **libigl** | 有 Python 接口，适合对 Python 更熟悉的同学 |
| **OpenMesh** | 经典半边结构网格库 |

## 三、微分几何基础回顾

### 3.1 曲线的微分几何

对于参数曲线 **c(u)**，在点 P = c(u₀) 处：

- **切向量（Tangent Vector）**：c'(u) = dc/du，方向与曲线在该点相切
- **二阶导数**：c''(u)
- **副法向量（Binormal）**：b = c'(u) × c''(u) 的方向
- **法向量（Normal）**：n = b × t（其中 t 为切向单位向量）
- 三者构成 **Frenet 标架（Frenet Frame）**，是相互正交的右手坐标系

> **退化情况**：若 c'(u) = 0（该点退化），Frenet 标架不成立。

**曲率（Curvature）κ**：
- 度量曲线在该点的弯曲程度
- 等于该点**密切圆（Osculating Circle）**半径的倒数
- 曲率大 → 圆半径小 → 弯曲厉害
- 直线曲率为零（等价于半径为无穷大的圆）

> **曲线的第一基本定理**：曲线的形状由每点的曲率唯一确定（相差一个刚性变换）。曲率是参数化无关的**内蕴几何不变量**。

### 3.2 曲面的微分几何

曲面由双参数表示：**S(u, v) = (x(u,v), y(u,v), z(u,v))**。

**偏导数**：
- S_u = ∂S/∂u = (∂x/∂u, ∂y/∂u, ∂z/∂u)
- S_v = ∂S/∂v = (∂x/∂v, ∂y/∂v, ∂z/∂v)

**切平面（Tangent Plane）**：S_u 和 S_v（线性无关时）张成的平面。

**曲面法向（Normal）**：
$$n = \frac{S_u \times S_v}{|S_u \times S_v|}$$

### 3.3 方向曲率（Directional Curvature）

在曲面某点 P，切平面中有 360° 无穷多个方向。对每个方向 t：
- 由法向 n 和方向 t 构成的平面与曲面相交，得到一条平面曲线
- 该平面曲线在 P 点的曲率即为该方向的**方向曲率** κ(t)

> **关键理解**：曲面上某点的切线不是单条线，而是切平面内的所有直线。谈论切线时需指定方向。

### 3.4 主曲率与欧拉公式

对曲面任意一点 P，在无穷多个方向中：
- 存在一个方向曲率最大，记为 **κ₁（最大主曲率）**
- 存在一个方向曲率最小，记为 **κ₂（最小主曲率）**
- 这两个方向**必定相互垂直**

> 这是微分几何中极为优美的性质，对任何曲面都成立。

**欧拉公式（Euler's Formula）**：任意方向 θ（与 κ₁ 方向的夹角）的方向曲率为：
$$κ(θ) = κ₁\cos²θ + κ₂\sin²θ$$

该公式说明任意方向曲率都是两个主曲率的凸组合（系数之和为 1），因此满足 κ₂ ≤ κ(θ) ≤ κ₁。

### 3.5 高斯曲率与平均曲率

由两个主曲率可定义两个重要曲率：

**高斯曲率（Gaussian Curvature）**：
$$K = κ₁ · κ₂$$

**平均曲率（Mean Curvature）**：
$$H = \frac{κ₁ + κ₂}{2}$$

### 3.6 高斯曲率的等距不变性

> **等距变换（Isometry）**：曲面上任意两点间距离保持不变的变换。

- 高斯曲率是等距变换下的**不变量**
- 例：将一张纸卷成圆柱或圆锥，纸上的度量距离未变，所以高斯曲率保持不变
- 平面的高斯曲率处处为零 → 圆柱和圆锥的高斯曲率也处处为零

> **反向定理**：处处高斯曲率为零的曲面，可以通过等距变换展开为平面。这种曲面称为**可展曲面（Developable Surface）**。

**三类经典可展曲面**：
1. **柱面（Cylinder）**
2. **锥面（Cone）**
3. **切线面（Tangent Surface）**：一条空间曲线所有切线构成的面，可以证明其必为可展曲面
4. 日常生活中"拿张纸随意扭一下"形成的面本质上是某种切线面

### 3.7 极小曲面（Minimal Surface）

**定义**：处处平均曲率 H = 0 的曲面。

**物理意义**：在给定边界条件下面积最小的曲面。例如肥皂泡在表面张力作用下自然收缩为面积最小的形状，即极小曲面。

**数学性质**：
- H = 0 意味着 κ₁ = -κ₂，即两个主曲率互为相反数（一正一负）
- 极小曲面上所有点都是**双曲点/鞍点（Hyperbolic Point）**，形状类似马鞍面
- 每个点一个方向凸、另一方向凹

**建筑应用**：
- 面积最小 → 节省材料与制造成本
- 每个点都是鞍点 → 水/雪等物质处于不稳定平衡，沿凹方向流走
- 屋顶不易积水积雪，避免被重雪压垮
- 多个获奖建筑作品使用极小曲面造型

### 3.8 曲面点的分类

| 类型 | 条件 |
|------|------|
| **椭圆点（Elliptic Point）** | κ₁ > 0 且 κ₂ > 0 |
| **抛物点（Parabolic Point）** | 其中一个主曲率为零 |
| **双曲点/鞍点（Hyperbolic Point）** | κ₁ > 0，κ₂ < 0（一正一负） |

## 四、离散微分几何：三角网格上的微分性质计算

### 4.1 核心问题

三角网格是分片线性的：三角形内部是平面（无穷阶光滑），但在边和顶点处仅有 C⁰ 连续，不可微。如何定义和计算网格顶点处的法向、曲率等微分几何量？

**背景**：网格顶点通常采样自某个未知的光滑曲面，该原曲面拥有确定的微分属性。目标是通过离散采样点估计出原始光滑曲面的微分属性。

### 4.2 两种计算思路

**方法一：连续逼近法（Continuous Approximation）**
- 取局部邻域内的点
- 用光滑曲面（如多项式抛物面、参数曲面、隐式曲面等）拟合这些点
- 用拟合曲面的微分属性估计原曲面的属性
- 优点：逼近阶可能较高
- 代表文献：2004 年的相关论文

**方法二：离散方法（Discrete Method）**
- 直接从网格的离散几何信息（边长、角度、面积等）推导微分量
- 基于离散微分几何（Discrete Differential Geometry）的理论体系
- 近 20 年来发展为活跃的研究领域

### 4.3 顶点法向估计

顶点 P 有多个相邻三角形，每个三角形有自己的法向。

**简单方法**：相邻三角形法向的平均值。

**加权平均**：按三角形面积加权（面积大 → 贡献大），得到更合理的估计：
$$n_i = \frac{\sum_{j \in N(i)} A_j \cdot n_j}{|\sum_{j \in N(i)} A_j \cdot n_j|}$$

### 4.4 离散平均曲率（Cotangent 公式）

顶点 i 的离散平均曲率法向（H·n）由**余切权重（Cotangent Weight）**公式给出：

$$H_i n_i = \frac{1}{2A_i} \sum_{j \in N_1(i)} (\cot\alpha_{ij} + \cot\beta_{ij})(v_i - v_j)$$

其中：
- **N₁(i)**：顶点 i 的**一邻域（1-Ring Neighborhood）**，即与 i 有一条边直接相连的所有顶点
- **αᵢⱼ, βᵢⱼ**：边 (i, j) 所对的两个角
- **Aᵢ**：顶点 i 的 **Voronoi 面积**（Voronoi Area）的两倍
- 该公式可从光滑曲面的 Laplace-Beltrami 算子离散推导得出

> **一邻域概念**：与顶点仅隔一条边的顶点集合。二邻域则再向外扩一圈。

### 4.5 离散高斯曲率

基于 Gauss-Bonnet 定理的离散化：

$$K_i = \frac{1}{A_i}\left(2\pi - \sum_j \theta_j\right)$$

其中：
- **θⱼ**：顶点 i 周围一圈相邻三角形在顶点 i 处的内角
- **Aᵢ**：顶点 i 的局部邻域面积
- 平面的高斯曲率为零：一圈角度之和恰为 2π

> **直观理解**：角度和与 2π 的偏差衡量了该点处的"弯曲"程度。偏差为零 → 平面；偏差为正 → 尖凸；偏差为负 → 鞍形。

### 4.6 曲率可视化

使用 **Color Map（颜色映射）** 技术：
- 定义颜色条（Color Bar），如蓝 → 绿 → 红对应最小值到最大值
- 将每个顶点的曲率值规范化到该区间并映射为颜色
- 红色区域曲率大（弯曲剧烈），蓝色区域曲率小（平坦）
- 适用面：高斯曲率、平均曲率等的可视化

经典参考文献：**"Discrete Differential-Geometry Operators for Triangulated 2-Manifolds"**（2003），详细推导了各类离散微分量。

## 五、极小曲面的迭代求解算法

### 5.1 离散平均曲率流

从平均曲率的余切公式出发，可将顶点 i 的离散平均曲率法向表达为：

$$H_i n_i \propto \sum_{j \in N_1(i)} w_{ij}(v_j - v_i)$$

其中 wᵢⱼ = cot αᵢⱼ + cot βᵢⱼ。

当 H = 0（极小曲面条件），即有：
$$\sum_{j \in N_1(i)} w_{ij} v_j - \left(\sum_{j \in N_1(i)} w_{ij}\right) v_i = 0$$

整理得：
$$v_i = \frac{\sum_{j \in N_1(i)} w_{ij} v_j}{\sum_{j \in N_1(i)} w_{ij}}$$

> **即顶点 i 应在它的一邻域顶点的加权重心坐标处，加权方式为余切权重。**

### 5.2 局部迭代算法

**算法步骤**：
1. 给定带边界的初始网格（例如开曲面）
2. **固定边界顶点**不动（模拟铁丝边界约束下的肥皂膜）
3. 对每个内部顶点：
   - 找到它的一邻域顶点
   - 计算加权重心坐标（用 cot αᵢⱼ + cot βᵢⱼ 做权重）
   - 计算目标位置与当前位置的差向量
   - 将该顶点沿该方向移动 λ（如 10%）的距离
4. 所有顶点同时更新完成一轮迭代
5. 重复迭代，曲面逐渐演化向极小曲面收敛

**收敛性**：理论上当迭代次数趋于无穷时，曲面趋向极小曲面。

### 5.3 关键注意事项

> **⚠️ 重要实现细节**：
> - **用旧顶点计算新位置**：一轮迭代中更新某顶点时，必须用迭代前的旧顶点坐标进行计算，不能使用已经被更新的邻居顶点。因此需要先存储所有旧坐标，全部计算完后再统一覆盖更新。
> - **步长 λ 应取较小值**：λ 推荐取 0.1～0.2。若 λ = 1（一次性移动到位），可能导致算法不收敛。λ 小意味着需要更多次迭代。
> - **边界顶点固定**：找到网格边界顶点并保持不动。
> - **封闭曲面**：若对所有顶点（包括边界）进行上述操作，曲面会不断收缩最终塌缩为一个点，这是该算法的特性。因此极小曲面求解针对**带边界的开曲面**。

### 5.4 边界识别

在半边结构中识别边界边：
- 内部边：被两个三角形共享（有两个相邻面）
- **边界边：只有一个相邻面**，即该边的 pair halfedge 没有对应的 face

**渲染层**（自底向上）：
- 图形接口：DirectX 12（目前仅支持 Windows）
- HLSL 着色器语言
- Buffer（顶点属性、索引）
- Shader（着色器程序）
- Texture（纹理图片）
- Material（材质，规定具体使用哪些贴图）
- Mesh（网格：顶点数组 + 索引数组）
- FrameGraph（并行渲染架构）
- Pipeline（标准渲染管线）

**逻辑层**：使用 **ECS（Entity-Component-System）** 架构

**编辑器层**：提供场景编辑、组件管理等功能

### 7.3 数学库设计

数学库将点（Point）、向量（Vector）、法向（Normal）等设计为不同类型，通过**组合（Composition）**方式复用公共功能：

| 组件 | 功能 |
|------|------|
| InnerProduct（内积） | 点乘、范数平方、距离平方、距离、余弦值等 |
| Metric（度量） | 距离、范数 |
| Affine（仿射） | 平移 |
| Add | 加法 |
| Scale | 数乘 |

**类型区别示例**：
- Point + Vector = Point ✅
- Point + Point = Vector ❌（点不能加点）
- Vector + Vector = Vector ✅

### 7.4 静态反射系统

C++ 原生缺少反射（C++20 最终未加入），因此框架自建了静态反射库。

**功能**：
- 将类的成员变量信息（名称、类型、属性）保存起来
- 允许在 Inspector 窗口中自动显示和编辑
- 修改成员变量后需要重新编译反射文件，UI 自动更新
- 支持属性约束（如最小值、提示文字等）

### 7.5 ECS 架构

**实体（Entity）**：场景中的对象，在 Hierarchy 中每条项目对应一个实体。

**组件（Component）**：纯数据集合，无逻辑功能。如：
- Position（位置）
- Rotation（旋转）
- EulerRotation（欧拉旋转）
- Translation
- LocalToWorld（局部到世界的变换矩阵）
- MeshFilter（网格数据）
- MeshRenderer（渲染器，使网格可渲染）

**系统（System）**：纯逻辑部分，与数据解耦。
- 每个系统规定了对具有特定组件组合的实体执行的操作
- 可在 System Control 窗口中激活/停用
- 读取某些组件，写入另一些组件，形成依赖关系图

**ECS 示例**：
```cpp
// 组件定义
struct Position { float x, y, z; };
struct Velocity { float vx, vy, vz; };

// 系统定义
void MoveSystem(Position& p, const Velocity& v) {
    p += v;  // 用速度更新位置
}
```

### 7.6 作业相关使用方式

**作业第六次数据流**：
1. 找到含有 `DeNoiseData` 组件的实体
2. 将目标网格（如 Bunny）拖入该组件的字段
3. 在 System Control 窗口中运行相关系统按钮：
   - **三角网格 → 半边网格转换**
   - 在半边网格上进行操作（如加噪声）
   - **半边网格 → 三角网格回传**（更新渲染数据）
   - 恢复原网格功能

**半边网格库（Edge Mesh）**：
- 基于模板的多边形网格库，支持三角形乃至任意多边形
- 预声明四种对象：顶点、边、多边形、半边
- 可自由添加属性（位置、面积、颜色等）
- 常用接口：
  - 遍历所有顶点
  - 获取顶点位置
  - `isOnBoundary()` 判断是否边界点
  - `adjVertices()` 获取一邻域
  - `degree()` 获取顶点的度

**调试**：使用 `spdlog` 输出信息到 Log 窗口。
