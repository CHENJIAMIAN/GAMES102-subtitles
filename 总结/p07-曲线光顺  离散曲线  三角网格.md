# 课程总结：曲线光顺（Fairing）与三角网格入门

## 一、作业点评：B样条与插值型细分实现

### 1.1 作业概况
- 本次作业主要实现 **B样条（B-spline）** 和 **插值型细分（Interpolatory Subdivision）**。
- 共提交 29 份，其中 10 份使用 C++ 等语言，部分同学延期提交。

### 1.2 细分方法回顾
- **Chaikin 细分**：二次细分，属于 **逼近型（Primal/主型）** 细分。
- **三次细分**：与二次细分在增加点和线的方式上有所不同。
- **四点细分（4-point Subdivision）**：属于 **插值型（Dual/对偶型）** 细分，实现简单。
  - 其中有一个参数 **α（阿尔法值）**，表示向量的偏移。
  - **α 在 0 到 1/8 之间时结果较好**。
  - 当 α 超过 1/8 时，曲线会变得怪异，产生 **分形（Fractal）** 效果。
  - α 越大，细分结果越杂乱。

### 1.3 优秀作业展示
- **王朝同学**：将 α 值超过 1/8，观察到分形现象；交互界面友好，可实时生成不同类型的细分（二次、三次、四点），可控制节点显示、细分次数。
- **长金俊同学**：实现了 2 次和 3 次细分，以及四点细分；将 α 固定为小于 1/8，避免分形；绿色多边形为输入，黄色为输出曲线。
- **项羽/陈同学**：鼠标点击有波浪动画反馈（良好的 UI 细节）；可实时调节 α 值，支持分形类型的实时控制。
- **另一位同学**：实时性更好，输入点时曲线即时生成；支持均匀三次 B 样条与四点细分，可编辑点与拖动。

> **强调**：优秀代码和报告将分享，供参考，但建议同学自己动手实现一遍以掌握原理。


## 二、曲线光顺（Curve Fairing）

### 2.1 光滑与连续的概念
- **连续性（Continuity）**：
  - **C0 连续**：位置连续（接牢）。
  - **C1 连续**：切线连续。
  - **C2 及以上连续**：通常称为 **光滑（Smooth）**。
- **几何连续性（Geometric Continuity）**：
  - 与参数化无关，刻画曲线本质的连续性。
  - 例：同一直线段，不同参数化下参数连续性不同，但几何连续性一致。
  - 更适合曲线设计，因为不依赖表达方式。

### 2.2 光顺（Fairing）的直观理解
- 英文术语：**Fairing**（来自 fair，意为公平、光顺）。
- 宏观上看起来光滑的曲线（甚至 C∞），在放大后可能呈现凹凸不平、歪歪扭扭。
- 判断方法：
  - 用手触摸（木匠常用）。
  - 打光看反射是否连续。
  - **看曲率图**（微观层面最可靠）。

### 2.3 曲率（Curvature）
- 曲率度量曲线在某点的 **弯曲程度**。
- **密切圆（Osculating Circle）**：在曲线某点与曲线有共同切线和共同曲率的圆。
- **曲率 k = 1/R**（R 为密切圆半径）。
  - 弯得厉害 → R 小 → k 大。
  - 越平 → R 大 → k 小。
  - 直线段曲率为 0（密切圆半径无穷大）。
- **曲率是参数化不变量**：与曲线本质有关，与参数表达无关。
- 空间曲线另有 **挠率（Torsion）** 概念，描述切线在垂直方向的变化速度。

### 2.4 光顺的定义与历史
- 光顺缺乏严格的数学定义，研究较少，但工业中非常重要（造船、汽车、制鞋、齿轮等）。
- **苏步青、刘鼎元** 的定义：
  - 曲线需 **C2 连续**。
  - 曲率图无多余振动（variation），曲率分布尽量均匀。
- **Farin** 的定义：
  - 曲率图应尽量少地交替递增/递减（单调段少）。
  - 后来修正为曲率图连续即可。
- **全局定义法**：
  - 以曲线 **曲率平方的积分**（弯曲能量）最小化为目标。

### 2.5 工程实践中总结的光顺准则（中国学者工厂实践）
1. 光顺不是全局问题，也不是局部问题，而是 **大局部问题**。
2. 不需要 C2 连续这么高的光滑性，可以更弱。
3. 必须从 **曲率** 出发研究光顺。
4. 举例：
   - y = sin(x)：C∞ 但拐点太多，不光顺。
   - 曲率图全正但自身有很多递增递减段，也不光顺。
   - 两个不同半径圆弧拼接处曲率突变，非 C2，不光顺。

### 2.6 光顺的四条准则（现代总结）
1. 曲线是 **C1 + L1**（比 C2 弱，变差连续）。
2. **拐点要少**。
3. **曲率图的拐点要少**（单调段少）。
4. **曲率图的变化振幅相对小**（不能突变）。

### 2.7 光顺方法（快速介绍）
- **粗光顺（Coarse Fairing）**：调整控制顶点，减少曲率振动。
- **卡尺法（Knot Removal / 压平）**：调整控制顶点，减少多余拐点，类似用尺子压平。
- **回弹法（Spring Back）**：类似物理放松，检查切变力符号，减少曲率振动数。
- 光顺过程需 **在误差允许范围内微调**，保持原始曲线形状基本不变。

### 2.8 非函数型曲线的光顺
- 函数型曲线有小挠度假设（y′ << 1，y″ ≈ k）。
- 一般参数曲线无此假设，可用 **稀疏优化（Sparse Optimization）** 方法，最小化曲率二阶差分的 L1 范数，同时约束原始曲线变化不要太大。

### 2.9 曲面光顺
- 早年：将曲面分解成两个/三个方向的曲线分别光顺再叠加（有局限）。
- 能量法：最小化主曲率的积分。
- **Class A 曲面**：工业界（如 CATIA）的高品质曲面，常要求 G3 连续以上。
- **曲率梳（Curvature Comb）** 和 **等照度线/斑马纹（Zebra Stripes）** 是检测光顺性的常用可视化工具。
  - 黑白条纹光滑 → 曲面光顺好。
  - 条纹弯曲扭动 → 曲面不光顺。

> **强调**：光顺在工业设计（造船、汽车等）中至关重要，影响流体阻力、磨损寿命和美观。


## 三、曲线曲面的映射观点与建模回顾

- 曲线曲面本质上都是 **从一个空间到另一个空间的映射**：
  - R1 → R1：一元函数。
  - R1 → Rn：曲线（n=2 平面曲线，n=3 空间曲线）。
  - Rm → Rn（m<n）：曲面（高维曲面）。
  - Rm → Rn（m>n）：降维/参数化（如曲面展开到平面）。
- **两种建模观点**：
  1. **拟合观点**：给定采样点 sj，求控制点 pi 使曲线拟合这些点（插值、逼近、回归）。
  2. **设计观点**：将 pi 视为用户直接操作对象，需要好的基函数（如 Bernstein 基函数具有局部性、凸包性等）。
- **曲线表达形式**：
  - 显式函数：y = f(x)。
  - 隐式函数：F(x,y) = 0，即二元函数的零等值面（图像处理中称为 **水平集 Level Set**）。
  - 参数形式：C(t)。
  - 细分曲线：离散表达，无限细分趋近光滑曲线。

### 3.1 PIA（Progressive Iterative Approximation）迭代拟合
- 一种从控制顶点反求拟合曲线的迭代方法：
  1. 由初始控制顶点构造曲线。
  2. 计算曲线上点与目标点的误差。
  3. 按误差调整控制顶点。
  4. 重复直至收敛。
- 实现简单，由 **齐东旭老师** 提出，后由利宏伟等发展。


## 四、离散曲线与采样定理

### 4.1 离散化的必要性
- **渲染必要**：光栅化只处理直线段/三角形，需将曲线离散成线段、曲面离散成三角形。
- **计算必要**：求交等运算用线段逼近曲线，误差可控即可。
- **制造必要**：数控加工中刀具只能走直线段和圆弧，必须离散。

### 4.2 采样定理（Nyquist-Shannon）
- 采样频率必须 **至少是信号最高频率的两倍** 才能无失真恢复原信号。
- B样条曲线采样可用 **细分（Subdivision）** 方法，误差可通过控制顶点与弦的距离估计。
- 精度要求 10⁻⁶ 时，细分 8 次即可。

### 4.3 离散曲线的几何量计算
- **拟合法**：先拟合连续曲线，再利用其解析微分。
- **差分法**：用相邻点的差分近似导数（弦斜率代替切线）。
  - 本质是用差商近似导数，一阶近似为线性，二阶近似为抛物线（类似梯度下降 vs 牛顿法）。


## 五、自由变形（FFD）与重心坐标（Barycentric Coordinates）

### 5.1 自由变形（Free-Form Deformation, FFD）
- 由 Sederberg（1986）提出。
- 思想：用少量控制顶点（如 n² 个）控制区域内无穷多个点。
- **代理（Proxy）**：用简单几何体（如控制网格）代理复杂形状，通过操作代理来变形目标。
- 应用：图像扭曲（Image Warp）、比萨斜塔纠正等。

### 5.2 重心坐标
- **三角形重心坐标**：
  - 任意内部点 p 可唯一表示为三个顶点的仿射组合：$p = \alpha p_1 + \beta p_2 + \gamma p_3$，$\alpha+\beta+\gamma=1$。
  - 几何意义：系数为相应小三角形面积与总面积之比。
- **多边形重心坐标**：
  - 四边形及以上不唯一，存在多种定义。
  - 著名类型：
    - **Mean Value Coordinates**：用角度 cot 和距离 r 定义。
    - **Harmonic Coordinates**：调和坐标。
    - **Wachspress Coordinates** 等。
- 重心坐标可用于图像变形、纹理映射等。
- 参考资源：瑞士 Horn 教授维护的重心坐标文献网站。


## 六、三角网格（Triangle Mesh）入门

### 6.1 三角网格基本概念
- 曲面离散为三角形片，每片是平面（线性函数），构成 **分片线性逼近**。
- GPU 渲染以三角形为单位，三角形光栅化硬件实现最简单。
- 网格本质上是 **二维流形上的平面图**。
- 数据结构：
  - **顶点（Vertex）**：三维坐标。
  - **边（Edge）**：连接两个顶点。
  - **面（Face）**：由边围成，三角网格中为三角形。
  - **度（Degree/Valence）**：与顶点相邻的边数（不规则，通常 3~6）。

### 6.2 流形（Manifold）
- **二维流形**：任意点的无穷小邻域与二维圆盘同胚。
- **非流形边**：一条边被三个及以上面共享。
- **非流形顶点**：邻域不连通（如两个锥体共顶点）。
- 本课程后续只处理流形网格。

### 6.3 拓扑概念
- **亏格（Genus）**：洞的数量（环=1，双环=2）。
- **可定向（Orientable）**：所有三角形方向一致（右手法则统一）。
- **莫比乌斯带**：非可定向曲面。
- **连通图/平面图**：网格可拍平为平面图，顶点坐标嵌入三维空间。

### 6.4 网格文件格式（OBJ）
- 文本格式示例：
  - `v x y z`：顶点（索引从 1 开始）。
  - `f a b c`：面（由顶点索引构成）。
- 四个顶点四个面可构成四面体。
- 建议使用成熟框架读写 OBJ，不必自己实现解析器。

### 6.5 网格数据结构
- **邻接矩阵**：存储点与点的连接关系（空间浪费，但适合某些矩阵运算）。
- **半边结构（Half-Edge）**：
  - 每条边拆为两个方向相反的半边。
  - 每个半边存储：起点、终点、所属面、配对半边等。
  - 查询相邻面/边非常快，是网格处理最常用的数据结构。
- **时空间权衡**：存储多则查询快，存储少则计算多，选择取决于应用场景。

### 6.6 课程框架
- 助教提供了基于半边结构的网格处理框架（中文名“无尽”）。
- 包含两套数据结构：
  - **计算数据结构**：半边结构，高效查询邻接。
  - **渲染数据结构**：自动转换并送入 GPU 渲染管线。
- 本周任务（非正式作业）：熟悉框架，尝试：
  1. 读取 OBJ 文件。
  2. 计算每个顶点的法向（用相邻面法向平均）。
  3. 沿法向对顶点做微小扰动（可调参数），观察效果。
